# Gate-0 synthetic fixture catalog

This catalog is test-only input. It is not a runtime result artifact and is
never used as a source of real media, model weights, or provider access.

`catalog.json` contains exactly seven deterministic entries:

| ID | Role covered |
| --- | --- |
| `cfr_4s` | CFR baseline |
| `vfr_nonunit` | VFR and non-unit time base |
| `vfr_negative` | nonzero/negative PTS origin |
| `duplicate_pts` | duplicate PTS |
| `missing_pts` | explicit missing-PTS coverage failure |
| `tie_oracle` | equal-PTS decoder-order tie |
| `boundary_end` | half-open window endpoint |

The six minimum v1.1 roles are represented by the first six role classes;
`boundary_end` is the additional endpoint oracle required by the
implementation plan. Golden files are authored checked-in oracles, not files
generated by the code under test.
