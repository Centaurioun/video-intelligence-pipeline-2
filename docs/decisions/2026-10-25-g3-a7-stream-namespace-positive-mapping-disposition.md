## §1 The question, decomposed

| # | Sub-question | Answer summary |
| --- | --- | --- |
| **Q1** | What is actually compared today? | A single Python `int` named `selected_stream_index`/`stream_index` that is **two different namespaces**: an FFprobe global stream index on the R1 side, and an all-`moov/trak` box ordinal on the R3/R4 side (`src/gate3/container.py:140-154,165-172,190-201`). |
| **Q2** | What would prove a correspondence? | Per-file, per-position **value identity** of a container field that both routes read independently, plus uniqueness/cardinality preconditions and fail-closed defaults. Nothing weaker is a proof; nothing stronger is available without a second demuxer. |
| **Q3** | Which such evidence exists at this base? | `ffprobe` already reports `streams[i].id == tkhd.track_ID` (hex string) and the R1 argv already persists it (`src/vip_fvs/real_source_probe.py:163-167,198-206`). The container side **never reads `tkhd`**, so half the proof is measured and discarded, and the other half does not exist (`src/gate3/container.py` has no `tkhd`; `src/vip_fvs/source_snapshot.py:201-252` bounds-validates only `mdhd`/`stts`/`elst`). |
| **Q4** | Can any purely ordinal/count heuristic be admitted? | **No.** Count equality, "all preceding streams are video", handler-sequence equality and 1:1-emission-in-box-order are all *implementation properties of the pinned demuxer*, not per-file evidence. They may corroborate; they may not admit. |
| **Q5** | What does continued refusal cost? | Every multi-trak input is refused at the refinement bind (`src/vip_fvs/refinement_adapter.py:194-217`) and the sole-video/`None`-selector case is refused at `:218-224`; that keeps IT-8 `PARKED_BLOCKED` (WBS `:252`). Nothing is *silently accepted* today (`E-15`). The residual costs are forward-looking: no consumer can detect a namespace divergence (§5 `G-4`/`G-5`) and the snapshot seal accepts an unvalidated derivation string (`G-6`). |
| **Q6** | Smallest admissible acceptance? | **Verified positional identity**: `probe_streams[i].id == traks[i].tkhd.track_ID` for **every** `i`, plus uniqueness and validity, plus the guarded `k` being the selected video stream. This is `P2` in §4. |
| **Q7** | What does that require? | A `tkhd` container fact (module placement = **matrix A-6** `(c) PENDING`, which approves `composed_temporal.py` only; a *second* container module needs the new **B-9**), conformant fixtures (`src/gate3/fixturegen.py:21` writes `track_ID = 0` today), and a decision on whether the *mapping proof* must be recorded in a sealed artifact or may be re-derived (schema/`stream_identity_derivation` value semantics = **A′-7 D-2 successor**). |
| **Q8** | What must stay refused forever? | Any ordinal/count/order inference without value identity; any mapping that would need a *guessed* correspondence; any acceptance the current artifact cannot express truthfully; any mapping whose container-side bytes were not re-measured (§7 `R-ID-REFUSE-*`). |

**One-sentence answer:** A-7 can be resolved *positively and safely* only by adopting **`P2` verified positional identity via `tkhd.track_ID`**; it cannot be resolved by any rule that uses ordinals, counts, or order alone, and it cannot be implemented before (a) the A-7 adoption decision, (b) a placement decision for the `tkhd` fact (A-6), and (c) a decision about where the proof is recorded.

## §7 Accepted / refused identity predicates

### 7.1 Accepted predicate — `ID-ACCEPT-POSITIONAL-TRACK-ID` (`P2`)

Given (a) the probe artifact `P` bound to source bytes `B` with `sha256(B) = P.source_bytes_sha256`, (b) the container parse of the **same** `B`, and (c) the selected FFprobe global index `k`, accept iff **all** hold:

1. **Bound evidence, with a named mode** — *either* (i) `named_bytes_remeasured`: the refinement byte-authority resolved the named source, re-hashed to the declared digest, and the container facts are the ones re-derived from those bytes (`refinement.py:56-120`; `container.py:205-283`, esp. the re-parse at `:262-275`), *or* (ii) `persisted_measurement_artifact`: a persisted artifact whose declared byte source resolves and whose facts reproduce exactly (`container.py:205-283`). A bare probe JSON with **no** declared digest is not bound evidence (`B-3`-relevant; independent review **B2**).
2. **Cardinality identity** — `len(P.streams) == len(direct moov/trak children of B)`; no trak is unexposed, no stream is trak-less.
3. **Structural `tkhd` validity, every position `i`** — every direct `moov/trak` has exactly one direct `tkhd` child; **the box header form is the canonical 8-byte form (`size != 1`)** — a large-size (`size==1`) `tkhd` is **refused** (`R-ID-REFUSE-TKHD-HEADER-UNSUPPORTED`), because it shifts the payload by 8 bytes and a box-relative `+20` read would land on `creation_time` (`R-24`, measured witness); `tkhd` version ∈ {0,1}; box length ≥ 92 (v0) / ≥ 104 (v1); the version-appropriate `track_ID` offset lies inside the box; the box is size-consistent with its parent. **The only permitted box reader is `container.py:60-73` `_boxes`, whose payload start is header-aware** (`pos+header`, `header ∈ {8,16}`).
4. **Identifier validity, every position `i`** — `tid_i := tkhd.track_ID` satisfies `0 < tid_i < 0xFFFFFFFF` (excludes the `0x0` fixture value, `E-3`, and the missing-`tkhd` sentinel / legal-max collision, `E-7`).
5. **Probe identifier validity, every position `i`** — `P.streams[i].id` exists, is a canonical lowercase `0x` hex string, and `int(id_i, 16)` is in the same strict range.
6. **Positional identity, every position `i`** — `int(P.streams[i].id, 16) == tid_i`. This is the per-file *field*-identity proof: it is *not* `id == i`, and it deliberately admits reversed ids (`E-5`). **Residual assumption, which must be stated wherever this is reported:** ffprobe's `streams[i].id` is produced by libavformat's `mov` demuxer reading `tkhd.track_ID` of *its own* trak at the same position (`E-1`); that attribution rule is a *demuxer implementation property*, not an independent measurement, and it is exactly the kind of property `§7.3` refuses to treat as evidence on its own. It is admitted here **only** because it is corroborated per-file by the container-side value at the same position, which no synthetic or documented ISO-BMFF shape in `E-23` contradicts.
7. **Uniqueness** — the `tid_i` are pairwise distinct (with 2+6 this makes the correspondence a bijection).
8. **Guarded selection** — `0 <= k < len(traks)`; `traks[k].handler == b"vide"`; `P.streams[k].codec_type == "video"`; `P.streams[k].index == k`.
9. **Timing authority** — the published timing facts are `traks[k]`'s, re-measured from `B` by the existing byte-authority path (`container.py:205-283`), with `media_timescale` and full `pts_ticks` unchanged.
10. **Demuxer-build currency (proposed, `B-10`)** — the recorded demuxer build that produced `P.streams[].id` matches the build under which `E-1`/`E-5`/`E-7`/`E-8` were measured (`ffprobe` 9.0.2). **Today the artifact records no build** (`real_source_probe.py:198-206`; `ffprobe` emits no version), so this condition is `BLOCKED_ON_B10`: until it is answered, acceptance is valid *for the measured build*, and the trust label must say so.

**What condition (2)/(3) must enumerate.** The `traks` list is *all direct `moov` children whose type is `trak`, in box order*, enumerated **before** the `_trak_timing` filter (`container.py:165-169`) — so `traks[i]` is the i-th `trak` **even if** it is not timing-bearing and even if it has no `mdhd`. A reader that enumerates only timing-bearing traks shifts `i` for every later position, and all nine checks can still "pass" against the shifted pair. This is the same construction the parser uses (`traks_index`), and it is the reason a video/soun/video or empty-`stts` layout is *not* a namespace hazard (`E-23`) but a *reader* hazard (`F-M7`).

Then, and only then: `stream_index := k` is simultaneously (i) the FFprobe global stream index and (ii) a **proven** all-`trak` ordinal. `k == j` is *established evidence*, never an assumption, which is exactly why the single-integer artifact remains truthful. **Trust label (mandatory):** "the ordinal correspondence was verified at bind time by positional `tkhd.track_ID` identity — two independent *parsers* (the repo's box reader and libavformat) reading the **same** field in the **same** bytes. It is **not** an ordinal assumption; it is **also not** independent corroboration from a second evidence source, and **must not** be described as a second demuxer confirming the first (`§11.4`)."

### 7.3 Non-predicates (explicitly not evidence)

`stream_count == trak_count` alone; `k == j` alone; "all preceding streams are video"; handler/codec-type sequence equality; `ffprobe` 1-stream-per-trak emission order (`E-4`); `format.duration`; nominal FPS; "it worked on every synthetic file" (`E-23`); any value read from Gate-0's `id`-suppressed probe route (`E-22`).

### 7.4 Case-class outcomes that the predicates must not blur

- **Identical characteristics, distinct `track_ID`s ⇒ ACCEPT.** This is the case that justifies `P2` over `P2u`: alternate/duplicate renditions are indistinguishable by codec, dimensions, timescale, or duration, and *are* distinguishable per file by position-wise `track_ID` identity.
- **VFR / source-native PTS.** The predicate changes **no** timing fact: the published `pts_ticks` stay the parser's sorted presentation PTS in `mdhd` ticks (`container.py` unchanged), the timebase stays `(1, media_timescale)`, and VFR classification stays where it is (`gate3/temporal.py:22`). No seconds×FPS derivation, no resampling, no reordering (`§11`).
- **Source immutability.** The predicate is a *read-only* function of the same digest-bound bytes; it must never write, normalize, remux, or "repair" the container (`refinement_adapter.py:164`,`:268-270`; `container.py:201`).
